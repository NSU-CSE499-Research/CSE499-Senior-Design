# Images and credits

All application images are included locally. They were downloaded from NASA-hosted sources for this educational prototype. No NASA insignia or wordmark is used; the Orbital Lab identity and interface are original to this project.

| Local asset | Description | Credit and primary source |
| --- | --- | --- |
| `assets/earthrise.jpg` | Apollo 8 Earthrise, 1968 | NASA / Bill Anders. [NASA Science resource](https://science.nasa.gov/resource/apollo-8s-iconic-earthrise/) |
| `assets/earth.jpg` | Apollo 17 Blue Marble, 1972 | NASA. [NASA image article](https://www.nasa.gov/image-article/apollo-17-astronauts-capture-iconic-blue-marble-50-years-ago/) |
| `assets/moon.jpg` | Lunar color texture, 1K equirectangular map | NASA's Scientific Visualization Studio; visualizer Ernie Wright (USRA), LROC and LOLA teams. [CGI Moon Kit](https://svs.gsfc.nasa.gov/4720/) |
| `assets/favicon.svg` | Orbital Lab symbol | Original SVG artwork included with the source |

The downloaded photographs and texture are unmodified files; the page uses cropping, overlays, and a stylized spherical presentation. NASA describes the CGI Moon Kit as optimized for aesthetics rather than scientific measurement.
